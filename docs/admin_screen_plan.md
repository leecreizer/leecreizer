# 설계 어드민 화면 기획서 (쿠홈 설계프로그램 스타일)

유통 채널별로 설계 페이지에 노출할 카테고리/콘텐츠/태그를 관리하는 어드민 시스템.

- 실행: `pip install flask` 후 `python run_admin.py` → http://localhost:5050
- 초기 계정: `admin / admin1234`
- 데이터: SQLite (`admin/admin.db`, 최초 실행 시 자동 생성 + 예시 데이터 시드)

## 전체 구조

```
로그인 ─ 대시보드
          ├─ 채널 · 그룹 · 사용자   (요구 #2)
          ├─ 카테고리 관리          (요구 #3)
          ├─ 콘텐츠 관리            (요구 #4, #5)
          ├─ 마스터 일괄등록        (요구 #6)
          └─ 태그 마스터            (요구 #7)
```

데이터 관계:

```
채널(channels) ─┬─ 사용자그룹(user_groups) ── 사용자(users)
                └─ 카테고리 노출(category_channels)
카테고리(categories, parent_id 계층) ── 콘텐츠(contents) ── 마스터(content_master)
태그폴더(tag_folders) ── 태그(tags) ── 콘텐츠-태그 매핑(content_tags)
```

## 1. 로그인 `/login`

| 항목 | 내용 |
|---|---|
| 입력 | 아이디, 비밀번호 |
| 검증 | 비밀번호 해시(pbkdf2) 비교, 비활성(중지) 계정 차단 |
| 동작 | 성공 시 세션 발급 → 대시보드. 미로그인 상태로 내부 URL 접근 시 로그인으로 리다이렉트(원래 경로 유지) |

## 2. 유통 채널별 사용자 그룹 관리 `/org`

한 화면에서 3단 구성: **채널 → 그룹 → 사용자** 순서로 상하 배치.

- **채널**: 코드/이름/설명/사용여부. 소속 그룹이 있으면 삭제 불가.
- **사용자 그룹**: 소속 채널 필수. 소속 사용자가 있으면 삭제 불가.
- **사용자**: 아이디/이름/비밀번호/권한(관리자·운영자·조회자)/소속 그룹/사용여부.
  - 수정 시 비밀번호를 비우면 기존 유지.
  - 마지막 관리자 계정은 삭제 불가(잠금 방지).
- 모든 추가/수정은 모달 다이얼로그로 처리.

## 3. 카테고리 관리 `/categories` — 설계 페이지 노출 연동, 계층(하이라키) 구조

- 무제한 깊이 트리(부모-자식). 시드 예시: 가구 > 침실 > 침대.
- 행마다: 이름, 콘텐츠 수, **채널별 노출 칩**(파란색=노출, 회색=미노출), 정렬 ▲▼, "+ 하위" 추가, 수정, 삭제.
- 수정 모달에서 **설계 페이지 노출 채널을 체크박스로 채널별 제어** — 설계 페이지는 이 매핑을 조회해 채널마다 다른 카테고리 트리를 노출.
- 이동 시 자기 자신/하위로의 이동(순환) 차단.
- 삭제는 하위 카테고리 포함이며, 콘텐츠가 1건이라도 있으면 차단.

## 4. 콘텐츠 관리 `/contents` — 카테고리별 등록·수정 리스트

- 필터: 카테고리(하위 카테고리 포함 검색), 상태(작성중/노출/숨김), 키워드(이름·코드).
- 리스트 컬럼: 코드, 이름, 카테고리 경로, 태그 칩, 마스터 등록 여부, 상태, 수정일시.
- 상태 뱃지: 노출(초록) / 작성중(노랑) / 숨김(회색).

## 5. 콘텐츠 마스터 정보 `/contents/new`, `/contents/<id>/edit`

등록/수정은 한 페이지 3단 구성:

1. **기본 정보**: 코드(고유), 이름, 카테고리, 상태, 썸네일 URL, 설명
2. **마스터 정보**: 브랜드, 모델번호, 판매가/원가, 단위, 가로·세로·높이(mm), 재질, 색상, 제조사, 원산지, 출시일, 메모
3. **설계리스트 노출 태그**: 태그 폴더별로 묶어 체크박스 선택

저장 시 콘텐츠+마스터+태그 매핑을 한 번에 upsert.

## 6. 콘텐츠 마스터 일괄등록 `/contents/bulk`

- **템플릿 다운로드**: 예시 행이 포함된 CSV(UTF-8 BOM, 엑셀 호환).
- **업로드 규칙**:
  - `콘텐츠코드` 기준 upsert (있으면 수정, 없으면 신규)
  - `카테고리경로`: `가구 > 침실 > 침대` — 없는 경로는 자동 생성(신규 카테고리는 전 채널 노출로 시작)
  - `태그`: `스타일>모던, 평형대>20평대` — 없는 폴더/태그 자동 생성, 폴더 생략 시 "미분류"
  - `상태`: 노출/숨김/작성중 (한글 그대로)
  - 인코딩: UTF-8(BOM) 우선, 실패 시 CP949(엑셀 한글 저장) 폴백
- **결과 리포트**: 신규/수정/오류 건수 + 행 단위 오류 메시지.

## 7. 태그 마스터 `/tags` — 콘텐츠 폴더별 설계리스트 노출용

- **태그 폴더**(예: 스타일, 평형대, 가격대) 단위로 태그를 묶어 관리.
- 태그: 이름, 색상, 사용여부, **사용 건수**(콘텐츠 매핑 수) 표시.
- 콘텐츠에 매핑된 태그가 있는 폴더는 삭제 차단. 태그 삭제 시 매핑도 함께 제거(확인 후).
- 콘텐츠 편집 화면과 일괄등록 CSV 양쪽에서 이 마스터를 참조.

## 공통 UX 규칙

- 좌측 고정 사이드바 내비게이션 + 현재 메뉴 하이라이트.
- 추가/수정은 모달, 삭제는 confirm 후 POST.
- 모든 처리 결과는 상단 플래시 메시지(성공=초록, 오류=빨강)로 피드백.
- 참조 무결성 보호: 하위 데이터가 있는 항목(채널·그룹·카테고리·태그폴더)은 삭제 차단하고 사유 안내.

## 향후 확장 후보 (확인 후 추가)

- 그룹/권한별 메뉴 접근 제어(현재는 로그인만 검증, role 필드는 준비됨)
- 콘텐츠 이미지 파일 업로드(현재는 URL 입력)
- 설계 페이지용 공개 API (`GET /api/channels/<code>/categories` 형태)
- 콘텐츠 일괄 다운로드(현재 보유 데이터 CSV 내보내기)
- 변경 이력(audit log)
